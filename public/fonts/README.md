# Bundled fonts

Latin subsets of three variable fonts, copied from the `@fontsource-variable`
npm packages (version 5.3.0) and bundled with the site so the published pages
have no runtime dependency on a font service.

| File | Family | Role | Licence |
| --- | --- | --- | --- |
| `fraunces-latin-full-normal.woff2` | Fraunces (all axes) | Editorial display face | SIL Open Font License 1.1 |
| `fraunces-latin-wght-italic.woff2` | Fraunces italic | Display emphasis | SIL Open Font License 1.1 |
| `inter-latin-wght-normal.woff2` | Inter | Body copy and controls | SIL Open Font License 1.1 |
| `inter-latin-wght-italic.woff2` | Inter italic | Body emphasis | SIL Open Font License 1.1 |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono | Mathematical notation only | SIL Open Font License 1.1 |

The licence texts are alongside the files.
